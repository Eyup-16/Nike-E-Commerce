# TrendCart 🛍️  
*A Modern E-Commerce UI Prototype*

A responsive frontend design for a fashion e-commerce platform. Built with pure HTML, CSS, and JavaScript .  


## Key Features 🎨  
- **Mobile-First Design**: Flawless responsiveness across devices  
- **Product Grid**: Clean card layout with hover effects  
- **Hero Section**: Full-screen banner with animated CTA  
- **Interactive Elements**:  
  - Cart counter animation  
  - Color switcher for product variants  
  - Smooth scroll behavior  
- **Modern Aesthetics**: Minimalist typography and color scheme  

---

## Tech Stack 💻  
- **HTML5** Semantic markup  
- **CSS3** Flexbox/Grid animations  
- **Vanilla JavaScript** DOM manipulation  
- **CSS Variables** Theming system  

---

## Usage 🖱️  
- Browse static product pages  
- Test responsive breakpoints  
- Interact with UI elements (cart, filters, etc.)  
- **Note**: This is a frontend prototype - no backend/database integration
